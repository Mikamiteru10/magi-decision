使用条款与隐私说明

生效日期：2026-11-14 · 维护者：Mikamiteru10/magi-decision

1. 这是什么

MAGI System 是一个非官方的同人娱乐项目，与 khara、GAINAX、Google 均无关联。三台 MAGI 的“承認 / 否定”由 Google 的决策模型 gemini-decision-1 给出，只是供参考的建议，不构成医疗、法律、财务、心理或任何其他专业意见。最终决定由你自己做出，并由你自己负责。

2. 年龄要求

本站仅面向年满 18 岁的用户。这是 Gemini API 使用条款的要求。未满 18 岁请不要使用。

3. 你输入的内容去了哪里

  • 你输入的提案和背景会通过本站服务器（Cloudflare Workers）发送给 Google Gemini API，用来得出三台 MAGI 的投票概率。
  • 本站使用 Gemini API 的付费服务。按照 Google 的条款，付费服务下 Google 不会用你的内容改进其产品，但会在有限时间内记录请求和响应，仅用于检测和防止违规使用。详见 Gemini API Additional Terms of Service。
  • 本站不保存你的提案、背景或结果，服务器日志里也不记录这些内容。
  • 本站不使用 Cookie、广告或统计脚本。“已满 18 岁”的确认只保存在你自己的浏览器里（localStorage）。

4. 防滥用措施

  • 本站使用 Cloudflare Turnstile 进行人机验证，并按 IP 地址限制请求频率。这些处理由 Cloudflare 完成，适用 Cloudflare 隐私政策。
  • 全站每天最多进行 3000 次审议（按 UTC 日期计算），超过后当天暂停服务。

5. 请不要输入

你自己或他人的敏感个人信息，例如真实姓名、证件号码、住址、联系方式、病历、财务账户等。描述问题时尽量概括，例如用“朋友 A”代替真实姓名。

6. 可用地区

Gemini API 只在部分国家和地区提供服务。在不受支持的地区（例如中国大陆、香港、澳门），审议功能无法使用。

7. 开源与联系

本站代码以 MIT 协议开源：github.com/Mikamiteru10/magi-decision。问题和建议请在 GitHub Issues 中提出。界面基于 itorr/magi（MIT）。

English summary

An unofficial fan project, not affiliated with khara, GAINAX or Google. Verdicts are advisory only and are not professional advice. Adults (18+) only. Your proposal is sent to the Google Gemini API (paid service: Google does not use it to improve its products, but logs requests for a limited time to detect abuse). This site does not store your text, uses no cookies or analytics, and keeps your 18+ confirmation only in your browser. Cloudflare Turnstile and per-IP rate limits protect against abuse; the whole site is capped at 3,000 deliberations per UTC day. Please do not enter sensitive personal information. Not available where the Gemini API is not offered.
